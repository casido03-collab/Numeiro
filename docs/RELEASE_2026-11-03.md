## Надёжность

- Пустой, оборванный или слишком короткий платный ответ не выдаётся как результат; демонстрационные ответы удалены.
- Основные семь услуг используют журнал `paid_results`: сначала сохраняется подготовленный текст, затем списывается доступ и создаётся запись истории.
- Списание по результату идемпотентно. При сбое базы после списания следующий запрос восстанавливает историю без второго списания.
- Ключ результата включает пользователя, язык, версию инструкции и точный контекст/период. Повтор входящего личного вопроса определяется идентификатором сообщения.
- Длинный ответ доставляется несколькими сообщениями целиком, без обрезки.
- Проверяются статус платежа через API ЮKassa, сумма, валюта и продукт. Повтор уведомления не выдаёт покупку дважды. Ошибка обработки возвращает 503 для повтора.
- Продление VIP и начисление покупок атомарны. Купленные разовые разборы больше не имеют скрытого срока сгорания через год.
- В старых диалогах платные ответы кэшируются до доставки; ошибки генерации сохраняют возможность повторной обработки.
- Убран искусственный восьмиминутный таймер и утверждения, что с клиентом говорит живой человек. Образ Аиши сохранён как цифрового помощника.
- Рекламные цепочки выключены по умолчанию; редиректная цепочка сокращена до одного напоминания. `/stop` отключает плановые сообщения, `/notifications_on` включает их.
- Сохранены найденные на сервере изменения контроля работоспособности, проверка исходников при запуске и отслеживание спонсорских переходов.

## OpenAI

Только прямой API OpenAI. Простые и стандартные задачи — `gpt-6-luna`; сложные — `gpt-6.1-terra`.
Параметры настраиваются через `OPENAI_MODEL_SIMPLE`, `OPENAI_MODEL_MEDIUM`, `OPENAI_MODEL_COMPLEX`.
Для установленного SDK 1.57 параметр `reasoning_effort=none` передаётся через поддерживаемый `extra_body`; совместимость проверена через реальный SDK и подменённый HTTP-транспорт.

Старый локальный ключ получил 401. Новый ключ введён владельцем локально, обе модели доступны. Выполнены четыре реальных запроса на синтетических примерах (личный вопрос и мини-разбор для каждой модели); ответы закончены, 238–248 слов, без продажи недостающей части. Это проверка работоспособности и нескольких примеров, не полномасштабное сравнение качества моделей.
